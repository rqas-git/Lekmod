# Navigation and discovery

Common routes: Single Player → Set Up Game → Advanced Setup for map/options;
Multiplayer → Internet or Local Network → Host Game for a network lobby; DLC on
the main menu controls installed official content. Mods may replace these menus.
[2K DLC guidance](https://support.civilization.com/hc/en-us/articles/37706836805907-Civilization-V-How-to-locate-DLC-content).

Inspect installed controls rather than guessing hotkeys: search for `CIV5Controls`,
`KeyDown`, `VK_F` and the relevant tooltip in the active UI. The official manual
contradicts itself about F5/F6 (technology versus social policies). Confirm those
bindings in this installation. Common stock bindings include F1 Civilopedia,
F2 economy, F3 military, F4 diplomacy, F8 victory, F10 strategic view, Enter next
turn, period next unit, G hex grid, Ctrl-R resource icons and Ctrl-Y tile yields.
F11/F12 quicksave/quickload and Ctrl-S/Ctrl-L save/load can change game state;
use the intended named save and verify the resulting turn.
[Official manual](https://downloads.2kgames.com/civ5/site13/community/feature_manual/Civ_V_Manual_English_v1.0.pdf).

Use city banners to open city screens, unit selection to expose valid orders,
and tooltips/Civilopedia links to answer local questions without switching screens
repeatedly. Record the current screen and pending modal; dismissing a dialog can
have different effects from accepting it. Resolve required production, research,
policy, promotion or stacked-unit actions before requesting the next turn.

Steam Mac saves normally live under `~/Library/Application Support/Sid Meier's
Civilization 5/Saves`; Mac App Store saves use the app's container. Windows uses
the logged-in user's Documents/My Games/Sid Meier's Civilization 5 profile.
Discover redirected Documents and private test profiles rather than assuming paths.
Aspyr documents Steam Internet play versus App Store Hotseat/LAN support;
experimental cross-platform mod tests need their own evidence.
[Aspyr Mac FAQ](https://support.aspyr.com/hc/en-us/articles/360020548611-Civilization-V-Mac-FAQ).
